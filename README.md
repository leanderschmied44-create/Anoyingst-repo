# Anoyingst-repo

This is an intentionally annoying collection of small, self-contained HTML experiments.

## Annoying CAPTCHA app

The root `index.html` file contains an annoying-but-usable CAPTCHA game. It starts with a compact Cloudflare-inspired verification widget, then reveals a second-step challenge after you click the checkbox. The challenge asks you to complete a randomly selected task, such as clicking a character's left foot, changing the weather, or making the sun disappear.

To open it:

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
3. Click the fake verification checkbox to reveal the challenge panel.
4. Complete the displayed challenge. After a success, a new random challenge appears automatically.

No build step, package install, server, or internet connection is required.

## Additional demos

The `annoying-htmls/` folder contains more playful annoying pages and its own landing page.
