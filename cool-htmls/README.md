# Cool HTMLs

A tiny collection of self-contained, upbeat HTML demos that are fun without being annoying.

## Pages

- `index.html` — A polished launchpad for the cool demos.
- `aurora-card.html` — A glowing aurora profile card with soft animated light.
- `glass-clock.html` — A glassy digital clock with animated ambient blobs.
- `tiny-garden.html` — A click-to-grow mini garden made with plain HTML, CSS, and JavaScript.
